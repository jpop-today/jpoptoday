## 기억나는 곡부터 저장하기

검색 결과와 곡 상세의 저장 버튼을 누르면 즐겨찾기에 추가됩니다. 이미 저장한 곡은 같은 버튼으로 해제할 수 있습니다. 제목이 비슷하면 원제와 가수를 먼저 확인하세요.

즐겨찾기에서 검색과 번호 조건을 적용해도 저장 목록 자체가 삭제되지는 않습니다. 조건을 해제하면 저장한 곡을 다시 볼 수 있습니다.

## 현재 브라우저에만 저장됩니다

즐겨찾기는 회원 계정이 아니라 현재 기기의 브라우저 저장 공간에 보관합니다. 다른 기기나 브라우저와 자동 동기화되지 않고, 사이트 데이터를 삭제하면 사라질 수 있습니다. 기기를 옮기거나 사이트 데이터를 지우기 전에 아래 방법으로 파일을 직접 보관하세요.

브라우저가 저장을 막거나 기존 자료가 손상된 경우 이 탭에서만 변경을 유지하고 안내합니다. 손상된 원본을 자동으로 덮어쓰지 않습니다. 임시 목록도 정상적으로 읽을 수 있다면 파일로 보관할 수 있지만, 파일을 만들 수 없다는 안내가 나오면 복구됐다고 생각하지 말고 화면의 목록이나 번호 메모를 따로 남겨 두세요.

## 즐겨찾기 전체를 파일로 보관하기

즐겨찾기에서 파일 보관·가져오기 안내를 열고 파일을 내려받으세요. 내려받는 JSON 파일은 현재 검색·필터와 관계없이 전체 저장 목록을 담습니다. 현재 곡 자료에서 찾지 못한 저장 항목도 함께 보관하므로, 화면에서 보이는 곡 수와 파일의 항목 수가 다를 수 있습니다.

파일에는 곡 식별자와 기존 저장 항목의 추가 정보가 들어갈 수 있습니다. 번호와 제목을 메모한 텍스트 목록과는 용도가 다릅니다. 파일은 본인이 다시 찾을 수 있는 곳에 보관하고, 다른 사람에게 전달하기 전에는 내용을 확인하세요. 앱이 이 파일을 서버에 업로드하거나 계정에 자동 보관하지 않습니다.

## 다른 브라우저에서 확인한 뒤 합치기

옮길 브라우저에서 이 사이트의 즐겨찾기를 열고 보관한 JSON 파일을 선택하세요. 파일 선택만으로 현재 목록이 바뀌지는 않습니다. 화면의 전체 항목 수와 현재 곡 자료에서 찾은 ID·다시 확인할 ID의 수를 읽은 뒤, 합치기 버튼을 직접 눌러 적용하세요. 이 개수는 파일의 ID를 현재 곡 자료와 대조한 결과이며, 이미 즐겨찾기에 저장한 곡과 겹치는 개수가 아닙니다. 파일을 가져오려면 JavaScript가 필요합니다.

합치기는 현재 목록을 비우거나 파일 내용으로 교체하지 않습니다. 기존 항목을 남겨 두고 아직 없는 곡 식별자만 추가합니다. 번호나 제목이 비슷하다는 이유로 다른 곡을 합치지 않고, 현재 곡 자료에서 찾지 못한 식별자도 보존합니다. 다시 확인할 항목이 있다는 사실은 해당 업체의 공식 미수록을 뜻하지 않습니다.

파일 형식이 다르거나 내용이 잘못됐거나 크기가 256KiB를 넘으면 가져오기를 거부합니다. 파일을 확인하는 동안 현재 저장 목록이 바뀌었다는 안내가 나오면 파일을 다시 선택해 확인하세요. 저장을 허용하지 않는 브라우저에서는 합친 결과가 임시 목록으로만 남을 수 있으므로, 영구 저장 성공 안내와 구별하고 탭을 닫기 전에 필요한 목록을 보관하세요.

## 번호 목록을 메모로 남기기

즐겨찾기의 번호 목록 복사는 현재 검색·필터 조건에 맞는 모든 저장 곡의 제목·가수·TJ·금영 번호와 상태를 복사합니다. 더 보기로 펼치지 않은 곡과 다른 페이지의 일치하는 곡도 포함합니다. 저장한 곡 전체를 복사하려면 검색과 필터 조건을 먼저 해제하세요.

복사한 목록에서도 업체마다 공식 확인, 관측·미확인, 확인 필요를 구분합니다. TJ가 공식 확인이어도 금영의 관측 번호까지 확인된 것은 아닙니다. 번호가 없거나 정정으로 제외됐거나 충돌하는 값은 번호 없이 확인 필요로 남깁니다. 확인 필요는 공식 미수록을 뜻하지 않습니다.

번호 목록 복사에는 JavaScript가 필요합니다. 브라우저가 자동 복사를 허용하지 않으면 선택 가능한 텍스트 창이 열립니다. 복사한 목록은 메모나 메신저에 붙여 넣을 수 있지만 다른 브라우저에 자동 등록하는 백업 파일은 아닙니다. 관측·미확인 번호는 제공사 검색에서 대조하고, 방문할 노래방의 업체와 최신 번호를 다시 확인하세요.
