# jpop.today v0.4.10

브라우저 데이터를 지우거나 기기를 옮기기 전에 즐겨찾기 전체를 JSON 파일로 직접 보관하고, 다른 브라우저에서 개수를 확인한 뒤 현재 목록에 합칠 수 있습니다. 기존 번호 목록 복사는 노래방에서 사용하는 별도 메모로 유지합니다.

- 안정 ID·미해결 ID·기존 저장 항목의 부가 정보를 보관하며, 가져오기는 기존 항목·순서·중복을 유지하고 새 ID만 추가합니다.
- 파일 선택과 확인은 저장 목록을 바꾸지 않습니다. 잘못된 형식·버전·ID·256KiB 초과를 거부하며, 확인 중 목록 변경·저장 거절·복구 미확인을 구분해 안내합니다.
- setlist 가이드와 개인정보 안내를 실제 기능에 맞췄습니다. 공식 근거 원장·동결 차트·카탈로그·기존 URL/저장 키·원래 색상은 유지했습니다. 파일은 서버에 업로드하지 않습니다.

단위·타입·정적 산출물·Chromium, 고정 SHA CI/미리보기와 실제 이전 운영 복구/재적용을 검증해 발행하는 제품 변경입니다. 모든 preview는 noindex·광고 없음이며 Google 계정·신청·승인은 미확인입니다. 운영자의 본인정보·약관/법적 동의와 실제 Google 심사 결과는 별도입니다.
