# jpop.today v0.4.4

기존 제목·가수 비교 가이드에 samfree/SAM 명의와 Ado 逆光의 생략된 공식 제목을 이유로 번호 확정을 보류한 실제 사례를 추가했습니다. 각 사례에서 기존 곡 상세로 바로 이동해 TJ의 공식 확인 근거와 금영의 관측 상태를 비교할 수 있습니다. 과거 조회 시각과 이번 본문 편집일을 구분하며 다른5가이드·기존4출처는 그대로 보존합니다. 새 번호 조회나 번호 확정은 수행하지 않았습니다.

실제 운영 HTML에서 Cloudflare Web Analytics 코드가 관측된 반면 개인정보 안내에는 분석 스크립트가 없다고 적혀 있던 불일치를 수정했습니다. 공식 설명에 근거한 방문·성능 통계 안내를 추가하고 광고·호스팅·즐겨찾기 처리와 구분했습니다. 전체 계정 설정·실제 분석 payload·법적 준수나 Google 승인까지 확인했다는 뜻은 아닙니다. 실제 ads.txt 응답은 존재하지만 현재 AdSense 계정과의 일치는 미확인입니다.

운영의 JavaScript-off 검사에서 Cloudflare 이메일 보호가 곡 제보 링크를 직접 사용할 수 없는 주소로 변환하는 결함도 확인했습니다. 공식 지원 HTML 범위 표시를 공개 곡 제보·문의·개인정보 이메일 링크에만 적용하며, 기존 주소·곡 제목/가수·제보 본문과 안정 URL을 보존합니다. 검사는 보호 주소를 복호화해 통과시키지 않고 실제 직접 mailto와 키보드 초점을 요구합니다. 최초 운영 29통과/2실패와 후속 같은 SHA 검증·배포·복구 결과는 실행 기록에 각각 보존합니다.
