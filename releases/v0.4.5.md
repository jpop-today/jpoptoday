# jpop.today v0.4.5

검색·홈·저장한 곡에서 TJ·금영의 공식 확인 조건을 선택할 수 있습니다. 두 업체를 함께 선택하면 양쪽에 실제 검토 근거가 있는 곡만 표시합니다. 기존 검색어·태그·관측 번호 조건과 URL·뒤로가기·저장 데이터를 유지하며, 결과0건을 공식 미수록으로 설명하지 않습니다. JavaScript 없는 화면은 현재 정적 목록에 필터가 적용되지 않음을 안내하고 검토된 정적 탐색 경로를 제공합니다.

동결 차트의 현재 playlist4곡을 대상으로 실제 공식 numeric 검색7건의 제목·가수·버전을 개별 대조했습니다. 기존77항목을 그대로 보존하고7confirm을 추가해 ledger84건이 됐습니다. 현재 확인곡은 TJ32·금영27·합집합32곡이며, Tani Yuuki의 미확보 금영번호와 기존 samfree/Ado 금영 판단보류는 그대로입니다. 조회 성공과 편집 판단을 분리하고 실제 조회시각을 새 차트 수집시각이나 권리·심사 결과로 바꾸지 않습니다.

실제360px 화면에서 드러난 검색·저장 행의 업체 배지 겹침과44px 미만 버튼을 좁은 컴포넌트 범위에서 수정했습니다. 원래 blue#4f7cff→pink#ff7aa8 및 pink/mint/blue 배경,3317안정ID·번호string·URL/localStorage·동결자료·실패시 마지막정상자료를 보존합니다. browser-safe boolean 판정과 서버 근거 projection이 같은 공식 numeric URL 규칙을 사용하며 엄격한 비공개자료 산출물 게이트를 유지합니다.
