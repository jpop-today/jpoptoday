# jpop.today v0.3.0

공식 검색 대조 결과를 번호 표시·검색·복사에 적용합니다. 잘못된 번호와 버전이 불명확한 번호를 복사 대상에서 제외하고, 일치한 번호에는 제공사 제목·가수·확인일·근거 링크를 표시합니다. 기존 3,317개 ID·URL·즐겨찾기 저장값을 유지합니다.

- 23개 ID에 대한 43개 검토 결과: 공식 대조 30건, 번호 억제 13건. 억제된 값은 확인 필요이며 미수록을 뜻하지 않습니다. 금영 unknown 4개를 보강하고 한국어판 1개의 잘못된 번호를 교체했습니다.
- 최신 보관 차트는 요청 기간 2026-09-29~2026-10-13, 실제 수집 시각 2026-10-13T10:26:45.525Z입니다. 100개 canonical ID로 연결하며 순위 변경 때 배열 위치로 다른 곡을 가리키지 않습니다. 부분·미래·쓰기 실패는 마지막 정상 자료를 보존합니다.
- preview 전체는 noindex·광고 없음입니다. production은 검토 콘텐츠와 공식 근거가 있는 현재 상세 24개 경로만 색인하고 sitemap·meta를 일치시킵니다. 검색·저장·나머지 상세·404는 noindex입니다.
- 기존 todayjpop/jpop.today에 조직 artifact를 배포하고 개인 Git 자동 배포를 가역적으로 중지하는 하네스와 Actions 경로를 추가했습니다. cloud binding을 Actions secret으로 복사하지 않습니다. 실제 배포 SHA·CI·원격 브라우저·복구 결과는 [운영 릴리스 기록](https://github.com/jpop-today/docs/blob/main/operations/releases/v0.3.0-20261014.md)에서 확인합니다.

로컬 계약 204개, 타입 검사 오류·경고 0개, 두 target의 artifact 검사, preview·production Chromium 각 14개를 검증했습니다. 미확인 페이지 색인·가짜 확인·광고 payload·비공개 보고 파일·잘못된 sitemap을 주입한 5개 artifact도 거부했습니다. 기존 파랑·분홍과 pink/mint/blue 배경을 유지합니다.

Google 계정의 실제 심사 결과는 unknown입니다. 광고·분석 스크립트는 포함하지 않으며 전체 카탈로그의 공식 확인이나 권리 허락을 주장하지 않습니다.
